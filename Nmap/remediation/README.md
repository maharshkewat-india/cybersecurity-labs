# Nmap Remediation

This folder contains defensive actions based on the authorized-lab scan findings.

## Files

- [`remediation-guide.md`](remediation-guide.md) prioritizes containment and service hardening, then provides safe, non-destructive verification examples.

## Use

Start with the [assessment findings](../documentation/findings.md) to understand which items were direct NSE results and which were only version-indexed references. Apply changes only to systems you own or are authorized to administer, and validate software versions and configuration with the system owner.

Return to the [Nmap project README](../README.md) for the scan summary and command.
